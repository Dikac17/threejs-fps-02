NEON HARBOR — a round-based tactical FPS in three.js on the BOATHOUSE map, a warm Mediterranean harbour town. Five Wardens (teal) against five Smugglers (brown/orange) with AI teammates and enemies — no real multiplayer. Buy weapons between rounds (Corsa AR, Sparrow 32 shotgun, Blade, frag/smoke/flash), plant the charge at Site A (Fish Market) or Site B (Boathouse), and hold the angles. Bots run routes, hold sites, rotate on the plant, and react to gunfire. First to 5 rounds takes the harbor.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click to play. WASD move, mouse look, click fire, right-click aim, R reload, 1–4 weapons, Ctrl crouch, Space jump, Shift sprint, Tab scoreboard, E hold to plant/defuse, B buy menu, G grenade, M mute, Esc pause. On touch devices: left joystick to move, drag right side to aim, on-screen FIRE / JUMP / CROUCH / RLD / WPN / NADE buttons.
